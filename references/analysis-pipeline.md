# 分析管线（analysis-pipeline）

> 本文件由 SKILL.md 按需加载：用户说"分析新歌单"、粘贴大批歌曲、或（ncm-cli 模式）用户同意拉取红心歌单/听歌排行时执行。

触发：用户说"**分析新歌单**"或粘贴一大批全新歌曲名，或（ncm-cli 模式）用户同意拉取红心歌单/听歌排行。

1. 立即停止推荐新歌，开始分析。
2. **多数据源**（能拿到的都用，交叉验证）：
   - 用户粘贴的歌单 / 红心歌单（ncm-cli 模式用 `playlist tracks` 分页拉全）；
   - 听歌排行（`user listen-ranking`，**含时间戳，"近期趋势"字段的真正来源**）；
   - 最近播放历史（`user history`）、收藏专辑（`album collected`）；
   - 用户自述（问答中的风格/排除/偏好描述）。
3. **元数据源**：以 Discogs（年代、流派、**制作人/作曲/编曲/乐手信用**）和 Apple Music 为准提取信息；BPM 按预估分布统计。**不使用网易云的曲风/BPM 标签**（不准确）。
4. **分析维度**：
   - **BPM 甜区**：对每个风格分支的代表曲目做 BPM 预估分布统计，写入画像"BPM 区间（按风格底线制）"；
   - **年代质感**：识别主要年代锚点；
   - **流派体系 + 分支识别**：提取核心流派；出现 1-2 次但风格独特的曲目单独聚类成"候选分支"，**列给用户确认**，不要被频次阈值静默丢弃；
   - **制作特征**：和弦、人声、混音风格；
   - **高频制作人（Discogs 信用数据）**：同一制作人/作曲家/编曲家/核心乐手出现 **2-3 次及以上**即视为高频，记入制作人库。**禁止用艺人频次代偿制作人频次**（制作人≠艺人，如 Nile Rodgers、Jimmy Jam & Terry Lewis 需要查信用数据才能发现）；
   - **近期趋势**：优先用听歌排行/最近播放的时间信息识别最近偏好变化，写入"近期趋势"字段（推荐时按约 40% 配额加权）；
   - **反向排除（必填）**：分析完成后必须向用户确认排除项——开放式提问（"有没有一听就跳过的歌/艺人/风格？"），并结合歌单数据给出可能的反向信号候选；**不预设任何默认排除流派**（严禁流派是用户画像数据，不是技能规则），用户确认后写入画像"严禁流派"；
   - **品味确认问答**：和弦色彩 / 人声质感 / 声场 / 歌词主题 4 组选择题（见 onboarding.md），回答写入画像对应字段。
5. **输出**：
   - 先输出一份简短的分析总结；
   - 然后把分析结果写入 `assets/user-profile.md`（不存在则按模板结构创建，已存在则更新对应字段），保持模板结构一致；
   - 请用户确认更新后的画像。
   - 注意：**不要改写本技能文件自身**，只更新画像文件。
