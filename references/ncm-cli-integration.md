# 可选集成：网易云音乐（ncm-cli）

> ⚠️ **可选功能**。仅当用户明确要求**创建歌单 / 播放 / 添加到网易云**时执行。
> 用户只要推荐曲目时，禁止启动本节流程。

## 前置风险提示（执行前告知用户）

- 本节依赖第三方命令行工具 ncm-cli，非本技能内置能力。
- npm 上存在多个同名包，安装前请用户自行核实包名与维护方（本仓库不保证任何包为"网易官方"出品）。
- 全局安装（`-g`）会修改用户全局环境，请在用户知情同意后进行。
- API Key / AppId / PrivateKey 必须由用户**本人**在网易云音乐开放平台申请，禁止使用他人的凭据。

## 启动条件

| 用户意图 | 动作 |
|---|---|
| 只推荐曲目 | 不启动 ncm-cli，按标准输出规范推荐 |
| 创建歌单 / 播放 / 添加到网易云 | 启动安装和登录流程 |

## 安装

```bash
npm install -g <核实后的包名> --legacy-peer-deps
```

## 歌单创建逻辑（防重复）

1. **只在用户明确要求创建/重建歌单时**才执行创建。
2. **创建前必须检查**：用 `playlist created` 查看已有歌单列表；若已有同名歌单：
   - 用 `playlist updateName` 将旧歌单重命名为 `[已废弃] 旧歌单名`；
   - **确认旧歌单已改名成功后再创建新歌单**。
3. 执行创建前，确保当前没有任何同名歌单存在（包括带"已废弃"标签的重名歌单）。
4. "重建"歌单的标准流程：
   - `playlist created` 获取所有歌单列表；
   - 找到同名歌单，`playlist updateName` 重命名为 `[已废弃] 原歌单名`；
   - **确认改名成功**后再 `playlist create`。

## 本模式附加约束

- **红心排除**：检查歌曲的 `liked` 字段，用户已红心（`liked: true`）的歌曲不推荐、不入歌单。（此约束仅在本模式生效——纯推荐模式下没有红心数据，自动跳过。）
- 每艺人不超过 1 首歌（必听专辑豁免）；如画像中配置了语言比例等个性化约束，按其配置执行。

## 歌单命名规则

- 用户**没有指定风格** → 歌单名用当前日期 + "AI推荐"，如 `2026-08-09 AI推荐`
- 用户**指定了风格**（如"给我建一个 Neo-Soul 歌单"）→ 歌单名用该风格名
- **禁止**在歌单名中使用场景/环境词（如"驾驶""雨天""通勤""微醺"等）
